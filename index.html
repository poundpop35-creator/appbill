⚪ ยังไม่ได้เชื่อมต่อ Google Sheet
วิธีตั้งค่า (ทำครั้งเดียว):
1. สร้าง Google Sheet ใหม่
2. ไปที่เมนู ส่วนขยาย (Extensions) → Apps Script
3. วางโค้ดที่ผู้พัฒนาให้มา แล้วกด Deploy → New deployment → Web app
4. ตั้งค่า "Who has access" เป็น Anyone แล้วกด Deploy
5. คัดลอกลิงก์ที่ได้ (ลงท้ายด้วย /exec) มาวางในช่องด้านบน

เมื่อเชื่อมต่อแล้ว ทุกครั้งที่กด 💾 บันทึกงาน ข้อมูลจะถูกส่งไปสำรองไว้ใน Google Sheet โดยอัตโนมัติ และทุกเครื่องที่เชื่อมต่อลิงก์เดียวกันจะเห็นรายการงานชุดเดียวกันในเมนู 📂 งานที่บันทึกไว้
